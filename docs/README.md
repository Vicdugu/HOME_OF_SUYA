# Home of Suya — Project Documentation

This folder tracks the build process, architecture decisions, and feature documentation for the system.

## Structure

| File | Purpose |
|------|---------|
| `README.md` | This file — overview and index |
| `build-log.md` | Step-by-step record of what was built and when |
| `architecture.md` | System design, data models, and tech stack |
| `features.md` | All features with descriptions and status |
| `deployment.md` | Step-by-step Vercel deployment guide |

---

> Documentation is kept in sync with the codebase.
> When a feature or function is removed from the code, its entry is removed here too.
